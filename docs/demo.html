Record the real customer journey

source .venv/bin/activate
npm --prefix docs install
npm --prefix docs run install-browser
python docs/record_storefront.py

The recorder starts a temporary backend on port 8601 with a catalog-only SQL clone, opens the real storefront in Chromium, creates a fictional customer, asks the live agents to search and update the cart, confirms an order through the real checkout form, and visits order history, profile and settings. Real customers, orders and stock are untouched. Memory is disabled for the temporary customer.

The output is docs/assets/storefront-tour.mp4. Long assistant waiting periods are trimmed; no response, product screen or successful action is fabricated. Use --headed to watch the browser when a graphical desktop is available.

A successful actual storefront recording is available: approximately 5 minutes 52 seconds, with real live agents and one synthetic order.
