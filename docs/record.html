Serve these docs on localhost, start the app, and use a new demo account with fictional contact details. This records the browser tab you select. Only perform the orders you want in that account; this is the real application.

Open marketplace

Use Chrome or Edge. Choose the marketplace tab when the browser asks what to share.

  1. Create a demo account, sign in, and open the assistant on the right.
  2. Ask: Show me apples and apple juice so I can choose. Select a product using its View button.
  3. Ask: Add it to my cart. Repeat research, viewing and adding for tea, whole wheat bread, Greek yogurt and mixed nuts. Then Change the Apples 1kg quantity to 2.
  4. Ask: Show my cart. Check the product, quantity and dollar total.
  5. Ask: Show calorie information for all Snacks products. Read the estimated calorie information.
  6. Ask: I want to checkout my cart. Use the quoted checkout form, a fictional address, and explicit cash-on-delivery confirmation.
  7. Ask: Show my previous orders. Review the purchased products.
  8. Visit Assistant settings to show per-user memory controls. Finish with the animated architecture and ERD tabs.
